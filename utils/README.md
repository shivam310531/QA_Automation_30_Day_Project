- Pytest
- Requests
- Flask
- MySQL

What I Have Practiced

- Python fundamentals and test-case logic
- SQL queries and database validation
- Python–MySQL database connectivity
- Web UI automation using Selenium
- API testing using Requests and Pytest
- Fixtures and parameterized testing
- API-to-database integration validation
- Git version control and branching

Project Setup

1. Clone this repository.
2. Install the required dependencies:

py -m pip install -r requirements.txt

3. Configure your environment variables in a ".env" file.
4. Run tests using:

py -m pytest

Project Objective

To develop practical skills in Automation QA by implementing real-world testing scenarios across UI, API, and database layers.
